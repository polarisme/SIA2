# Integrated System logo

Poultry Farm Operations & Accounting Management System logo (chicken + peso-symbol
identity, green color family).

Expected filenames:

| File | Purpose |
|---|---|
| `integrated-logo.png` | Primary logo (used by default) |
| `integrated-logo-mark.png` | Icon-only mark, no wordmark (for compact spaces) |
| `integrated-logo-light.png` | Light variant, for dark backgrounds |
| `integrated-logo-dark.png` | Dark variant, for light backgrounds |
| `integrated-favicon.png` | Browser tab icon |

Place files directly in this folder using the names above. `logo_url('integrated', variant)`
in `shared/includes/bootstrap.php` resolves to these paths once they exist.
